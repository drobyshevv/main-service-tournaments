# Main Service

**Main Service** — это микросервис платформы для проведения турниров.  
Он отвечает за бизнес-логику приложения, управление турнирами, участниками, матчами и взаимодействие с остальными сервисами системы.

## Зона ответственности

Main Service реализует ключевую доменную логику системы турниров:

1. **Создание и управление турнирами**  
2. **Регистрация и управление участниками**  
3. **Формирование сеток и расписаний матчей**  
4. **Учёт результатов матчей**  
5. **Расчёт турнирных таблиц и прогресса**  
6. **Хранение и выдача основной информации для фронтенда**  
7. **Публикация событий для других сервисов**

## Ограничения ответственности

Сервис **не занимается** следующими задачами:

- Аутентификация и авторизация пользователей  
- Отправка уведомлений пользователям  

Эти функции реализованы в отдельных микросервисах системы.

## Конфигурация

Сервис настраивается:

- через переменные окружения  
**или**
- через путь к конфигурационному файлу  

Конкретный способ зависит от окружения запуска (локально, Docker, Kubernetes и т.д.).
